# Pocket Atlas design
Apple-inspired map workspace: full-bleed real map with a floating library panel on desktop and an expandable bottom sheet on mobile. White and grouped-gray surfaces, readable system sans typography, blue actions, subtle translucent map controls. No simulated device chrome. Existing custom pin colors remain user data. Primary tasks: import from AMap, drop a pin, inspect saved places, navigate. Backup and manual-coordinate tools live in the map menu. Place details show a reading view first, with editing on request. Motion is limited to sheet transitions and respects reduced motion.
